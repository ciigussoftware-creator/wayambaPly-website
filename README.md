## Features

- Modern single-page layout with a plywood-inspired visual theme
- Fully responsive design for desktop, tablet and mobile devices
- Product information for W.B.P. commercial plywood sheets and boards
- ITI laboratory test results and certification details
- Product and certification image gallery
- Direct telephone, WhatsApp and email contact links
- Embedded Google Maps location for the factory

- Dynamic copyright year in the footer
- Custom favicon and Apple touch icon support
- Google Analytics 4 integration for visitor and engagement tracking

## Run Locally

No package installation or build process is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/ciigussoftware-creator/wayambaPly-website.git
   ```

2. Open the project directory:

   ```bash
   cd wayambaPly-website
   ```

3. Open `index.html` in a browser, or use the **Live Server** extension in Visual Studio Code.

## Deployment

The website is deployed through **GitHub Pages** and connected to the custom domain `wayambaply.lk`. Changes pushed to the deployment branch are published automatically after GitHub Pages finishes building the site.
